# Ratul Ali — Personal Academic Website

This is the personal academic website of **Ratul Ali** (Abdur Rahim Ratul Ali Khan), Research Programmer & CyberSecurity Analyst (.NET & AI/ML), CEH — based in Dhaka, Bangladesh.

Built with [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

## Customized Files

| File | Description |
|------|-------------|
| `_config.yml` | Site configuration for Ratul Ali |
| `_pages/about.md` | Homepage / About section |
| `_data/cv.yml` | Full CV data |
| `_data/socials.yml` | Social media links |
| `_data/coauthors.yml` | Co-author links |
| `_bibliography/papers.bib` | Publications in BibTeX |
| `_news/` | Timeline news items |
| `_projects/` | Project pages |
| `_pages/cv.md` | CV page |
| `_pages/publications.md` | Publications page |
| `_pages/projects.md` | Projects page |
| `_pages/services.md` | Services & talks page |

## Setup

```bash
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000`
