## Overview

**CEFFRL** (Configurable and Extensible Framework for Fuzzy Record Linkage) is an open-source toolkit for flexible record linkage in .NET applications, enabling robust data deduplication and entity resolution across large-scale datasets.

## Key Features

- Configurable fuzzy matching algorithms
- Extensible architecture following Clean Architecture principles
- Compatible with .NET Core and .NET Framework
- Handles noisy, inconsistent, and incomplete data
