## Overview

Designed and implemented mission-critical banking systems at **Shahjalal Islami Bank PLC**, combining application development with SOC security operations using enterprise-grade security tools.

## Systems Developed

- **IDMS (Investment Document Management System)** — Secure handling of confidential investment records
- **CCAPTS (Credit Card Application Process Tracking System)** — Automated customer onboarding
- **BMMS (Meeting Agenda Management System)** — Functional upgrades using ASP.NET MVC

## SOC Operations

- Monitored enterprise security using **Trend Vision One™**, **Trellix**, and **Tenable**
- Performed vulnerability assessments and managed CVEs for risk mitigation
- Compliance with ISO 27001, NIST, and CERT frameworks
- Backend performance and load testing using JMeter for DIGI BANK APIs

## Technologies

`.NET Core` `Angular` `PostgreSQL` `ASP.NET MVC` `Entity Framework` `Trend Vision One™` `Trellix` `Tenable` `JMeter`
