## Overview

Spearheaded end-to-end design and development of multiple health data management platforms at **icddr,b**, in collaboration with **Emory University, USA**.

## Systems Developed

- **LC Data Portal** — Centralized data management for Longitudinal Cohort studies
- **CHAMPS Data Request Portal** — Streamlined data access requests for the CHAMPS Repository
- **LC HDSS Reporting System** — Automated reporting for Health and Demographic Surveillance System
- **CHAMPS LC DSS App** — Android application for field data collection
- **Pneumonia Survey App** — Mobile survey tool for pneumonia research

## Key Contributions

- Engineered MS SQL Server databases ensuring integrity and security of large-scale medical research data
- Applied Clean Architecture principles across the full SDLC
- Collaborated with medical researchers to improve data collection workflows
- Provided technical training for knowledge transfer

## Technologies

`C#` `Angular` `.NET Core` `MS SQL Server` `TypeScript` `Clean Architecture` `Android`
